# AGENTS.md

Instructions for any agent working in this repository.

## Mission

Make the Velnor self-hosted runner the default CI/CD runner across 36 repositories
(`jackin-project`, `ChainArgos`, `tailrocks` orgs — see `scripts/repos.txt`), then make every
default branch and every open PR green on Velnor. Full goal definition: `START.md`.
Resume instructions: `RESUME.md`. Phases: `PLAN.md`.

## Rules

1. **Always commit and push your work.** After every meaningful change: `git commit -s`
   (DCO signoff) and `git push`. Never leave work uncommitted or unpushed — this repo is the
   control room, its state must survive interruptions.
2. **Never stop until the goal is fully achieved.** Keep iterating the `START.md` working
   loop until `scripts/audit.sh` reports all 36 repos ✅ (runner default VELNOR, main green
   on Velnor, open PRs green). Do not pause for confirmation between repos.

## Hard constraints

- Never merge PRs with admin privileges (`gh pr merge --admin`) and never bypass branch
  protection. Fix the check; updating required-check lists to match renamed workflows is fine.
- Velnor runner is always the default. GitHub-hosted runners only as a temporary,
  non-default fallback when the Velnor fleet is down — revert afterwards.
- One PR per repo per logical change. Conventional commit messages. DCO signoff on every commit.
- Never disable or delete a workflow just to make CI green. Fix the root cause.
- Never print, exfiltrate, or commit secrets.
